# Curriculum

**Zone intermédiaire.** Généré à l'intake, **puis propriété de l'apprenant** : jamais
écrasé par une mise à jour du moteur, jamais régénéré silencieusement. Édite-le à la
main quand tu veux. Un ajout de fichier dans `cours/` propose un **diff** ; il ne
réécrit rien.

> **Statut : non initialisé.** Lance `/intake`.

Si le parcours est **minimal**, ce qui saute est listé ici, en clair, avec le risque
pris. Le triage se fait sur les annales et le barème quand ils existent, sur la
centralité dans le graphe sinon. **Triage, pas réordonnancement** : on garde l'ordre
pédagogique et on saute, sinon les dépendances cassent.

## Concepts hors-support

_Tout concept sans source identifiée est marqué ici, pas dans un module. C'est le
garde-fou anti-hallucination, et il n'est pas négociable : un module inventé fait
travailler l'apprenant sur une matière qui ne tombera pas._
